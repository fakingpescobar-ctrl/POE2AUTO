# assets — медиа для README

Здесь лежат картинки/гифки, которые показывает главный `README.md`. Сейчас это
**плейсхолдеры** — замени их реальными записями игры, **сохранив имена файлов**
(тогда README обновится сам, без правок разметки).

| Файл | Что записать |
|------|--------------|
| `demo-loot.gif` | Авто-подбор лута (F8): персонаж двигается, бот добивает pickup, пока лут в радиусе. 5–10 с. |
| `demo-flask.gif` | Авто-фляска: просадка HP в бою → бот жмёт L2. Хорошо, если в кадр попал оверлей с `HP%`. 5–10 с. |
| `demo-overlay.png` | Скриншот оверлея статусов поверх игры (со строкой «Калибровка HUD: захват ✓»). |

## Как записать гифку (бесплатно)

- **ScreenToGif** (<https://www.screentogif.com/>) — запись области экрана сразу в `.gif`, можно
  обрезать кадры и снизить вес.
- Или **ShareX** (<https://getsharex.com/>) → «Capture region» → «Animated GIF».

Советы: держи гифку короткой (5–10 с) и узкой областью (орб + кусок экрана вокруг персонажа), чтобы
файл был лёгким (в идеале < 5–8 МБ — иначе медленно грузится на гитхабе). Перед записью убедись, что
оверлей виден (**F6**), а диагностика выключена (**F7 off**), чтобы fps не проседал.
