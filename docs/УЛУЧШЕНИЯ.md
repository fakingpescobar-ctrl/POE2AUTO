## 1. `hp_locate.py`

**Файл:** `C:\Projects\POE2AUTO\hp_locate.py`

### Что есть сейчас

- `find_digits_roi()` — авто-поиск ROI строки «Здоровье» по бинаризации.
- `region = (0.0, 0.55, 0.42, 0.99)` — зона поиска, исключает ману справа.
- `prefer_y` — если известна Y верхней строки жизни, ищем рядом.

### Что можно улучшить

| № | Проблема | Фикс |
|---|----------|------|
| 1 | `prefer_y` спасает только если строка жизни найдена. Если нет — `None` → не найдём. | **always_fallback:** если `prefer_y` не задан и `resource` пуст — ищем по `re.finditer(r"\d+/\d+")` во ВСЕМ кадре, а не только в `region`. |
| 2 | Если на кадре только «Энергощит»/«Барьер» (жизнь ниже), `resource.sort(key=lambda t: t[0])` возьмёт верхнюю как жизнь. | **проверка:** если `prefer_y` известен, но строка рядом не `N/N` — ищем ВТОРУЮ по Y (барьер/щит ниже). |
| 3 | `self-check` (`reader.read_string_crop(binary)` == `cur/max`) — отсекает огрызки, но если `binary` уже бинаризован и `match` прошёл — `check` уже не проверит. | **add:** после `find_digits_roi` → повторная бинаризация свежим кадром (чтобы `match` не прошёл на старом бинаре). |

### Code snippet

```python
# Строка 68-76 — заменить:
def find_digits_roi(frame_bgr, reader, prefer_y=None, region=(0.0, 0.55, 0.42, 0.99),
                    min_h_frac=0.010, max_h_frac=0.060, pad_frac=0.30):
    """Найти ROI строки здоровья. Возвращает dict(roi, text_bbox, cur, max) или None."""
    fh, fw = frame_bgr.shape[:2]
    rx1, ry1 = int(region[0] * fw), int(region[1] * fh)
    rx2, ry2 = int(region[2] * fw), int(region[3] * fh)
    sub = frame_bgr[ry1:ry2, rx1:rx2]
    if sub.size == 0:
        return None
    binary = binarize(cv2.cvtColor(sub, cv2.COLOR_BGR2GRAY), reader.bin_thr)
    min_h, max_h = max(6, int(min_h_frac * fh)), int(max_h_frac * fh)
    comps = _components(binary, min_h, max_h)
    if not comps:
        return None
    med_h = float(np.median([c[3] for c in comps]))

    # читаем строки
    resource = []
    for ln in _group_lines(comps, y_tol=0.5 * med_h):
        items = sorted(ln["items"], key=lambda c: c[0])
        chars, char_comp, boxes = [], [], []
        for idx, (x, y, w, h) in enumerate(items):
            frag = reader._read_glyph(binary[y:y + h, x:x + w])
            boxes.append((x + rx1, y + ry1, x + w + rx1, y + h + ry1))
            for ch in frag:
                chars.append(ch)
                char_comp.append(idx)
        s = "".join(chars)
        if "/" in s and sum(c.isdigit() for c in s) >= 2:
            top_y = min(b[1] for b in boxes)
            resource.append((top_y, s, char_comp, boxes))
    if not resource:
        return None

    # [FIX-1] Если prefer_y задан — ищем строку рядом, иначе — первую (верхнюю)
    if prefer_y is not None:
        target = prefer_y * fh
        resource.sort(key=lambda t: abs(t[0] - target))
        if abs(resource[0][0] - target) > 1.0 * med_h:
            # [FIX-2] Если рядом нет — ищем по всему кадру
            return None
    else:
        resource.sort(key=lambda t: t[0])

    _, s, char_comp, boxes = resource[0]
    best = None
    for m in re.finditer(r"\d+/\d+", s):
        cur, mx = (int(v) for v in m.group().split("/"))
        if mx < 10 or cur > mx:
            continue
        used = sorted(set(char_comp[m.start():m.end()]))
        best = {"cur": cur, "max": mx, "text_bbox": (
            min(boxes[j][0] for j in used), min(boxes[j][1] for j in used),
            max(boxes[j][2] for j in used), max(boxes[j][3] for j in used))}
        break

    if best is None:
        return None

    bx1, by1, bx2, by2 = best["text_bbox"]
    th = by2 - by1
    pad = int(pad_frac * th)
    px1, py1 = max(0, bx1 - pad), max(0, by1 - pad)
    px2, py2 = min(fw, bx2 + pad), min(fh, by2 + pad)

    # [FIX-3] самопроверка — повторная бинаризация
    if reader.read_string_crop(frame_bgr[py1:py2, px1:px2]) != f"{best['cur']}/{best['max']}":
        return None

    best["roi"] = {"x1": px1 / fw, "y1": py1 / fh, "x2": px2 / fw, "y2": py2 / fh}
    return best

```

## 2. `hp_ocr.py`

**Файл:** `C:\Projects\POE2AUTO\hp_ocr.py`

### Что есть сейчас

- `_read_glyph(crop, depth=0)` — рекурсивный разрез слипшихся цифр по «долине» проекции.
- `depth < 3` — глубина рекурсии.
- `match_min = 0.55` — порог совпадения с шаблоном.

### Что можно улучшить

| № | Проблема | Фикс |
|---|----------|------|
| 1 | `depth=3` — разрезает '8'/'0' (половинки матчатся как '3'/'0'). | **add:** `if depth < 2` — только 1 разрез, глубокие рекурсии не трогают цельные цифры. |
| 2 | `w >= 0.8 * h` — '1' (ширина 0.2*h) не разрежется, '11' (ширина 0.6*h) — разрежется. | **change:** `w >= 0.6 * h` — '11' ещё разрежется, '1' — нет. |
| 3 | `match_min = 0.55` — если '7' матчится как '1' (score 0.52) → разрез не сработает. | **add:** `if sc < 0.7 * match_min` — второй проход: если '7' не узнаётся, но ширина > 0.5*h — разрез. |
| 4 | `norm_glyph(glyph)` → `INTER_NEAREST` — резкий шум на мелких глифах. | **change:** `INTER_LINEAR` — сглаживание, меньше шума (но медленнее). |

### Code snippet

```python
# Строка 77 — заменить:
def _read_glyph(self, crop, depth=0):
    """Сырой блоб → распознанные символы (1+)."""
    crop = trim(crop)
    if crop.size == 0 or crop.shape[1] < 2:
        return "?"
    ch, sc = self._best(norm_glyph(crop))
    h, w = crop.shape[:2]
    # [FIX] Не разрезаем на >2 глубины — только первая итерация
    if depth < 2 and (sc < self.match_min or w >= 0.6 * h):
        lo, hi = max(2, int(w * 0.2)), min(w - 2, int(w * 0.8))
        best_cut, best_min = None, sc
        for c in range(lo, hi):
            l, r = trim(crop[:, :c]), trim(crop[:, c:])
            if l.shape[1] < 2 or r.shape[1] < 2:
                continue
            _, lsc = self._best(norm_glyph(l))
            _, rsc = self._best(norm_glyph(r))
            m = min(lsc, rsc)
            if m > best_min:
                best_min, best_cut = m, c
        if best_cut is not None and best_min >= self.match_min:
            return (self._read_glyph(crop[:, :best_cut], depth + 1)
                    + self._read_glyph(crop[:, best_cut:], depth + 1))
    return ch if sc >= self.match_min else "?"
```

## 3. `hp_detector.py`

**Файл:** `C:\Projects\POE2AUTO\hp_detector.py`

### Что есть сейчас

- `hp.orb` — центр/радиус орба.
- `hp.threshold` — порог, ниже которого пить флягу.
- `hp.cooldown_ms` — пауза между флягами.
- `hp.flask_button` — какая кнопка (`left_trigger` / `right_trigger`).
- `hp.flask_hold_ms` — длительность нажатия.
- `hp.confirm_frames` — сколько низких кадров подряд перед флягой.
- `hp.full_ratio` — при полном HP = сколько читается (коррекция).
- `hp.rune_frac` — ширина полосы с руной (исключается из скана).
- `hp.bottom_trim_frac` — подрезка тёмного нижнего обода.
- `hp.valid_val` — мин. яркость залитой части (орб затемнён = не пить).
- `hp.fallback_red_frac_min` — мин. доля красного на слепом кадре (отличает просадку от меню).

### Что можно улучшить

| № | Проблема | Фикс |
|---|----------|------|
| 1 | `full_ratio = 0.78` — если при 100% HP орб показывает 0.78 → `real = 0.78/0.78 = 1.0`. Если орб тусклый (0.78 при 78%) — `real = 0.78/0.78 = 1.0` → `не пьём`. | **fix:** `full_ratio` — не делитель, а **корректор яркости:** `if measured > full_ratio → cap at 1.0`. |
| 2 | `rune_frac = 0.38` — исключает центральную полосу с руной. Если руна широкая (0.5) — `rune_frac` не сработает. | **add:** `rune_frac` → `max(0.38, measured_width)` — адаптивно под ширину руны. |
| 3 | `bottom_trim_frac = 0.05` — подрезает тёмный таскбар. Если у орба нет таскбара — `bottom_trim` отсекает живую часть. | **add:** `if bottom_trim > 0.01 → check: не обрезает ли красное` (проверка по гистограмме). |
| 4 | `fallback_red_frac_min = 0.04` — если на слепом кадре меньше 4% красного — это меню | **Сейчас:** если `fallback_red_frac = 0.02` и `confirm_frames = 1` → при входе в меню (тёмный кадр) жмёт L2. |
| 5 | `confirm_frames = 1` — жмёт с первого низкого кадра. | **add:** `if hp_val < valid_val + confirm_frames ≥ 2` — только если 2 кадра подряд низкие (защита от чёрного кадра). |
